Entry to make.fun's bounty "u-danu-how-many-tabs-do-you-have-open-d86e783d":
one honest, believable count of the browser tabs open while working.

The number:

    137

A prime, not a round target: the sort of count a real tab hoarder has
after a long day of docs, issues, pull requests and "read later" pages
piled up with nothing closed.

## Run

    node main.ts

Node 22 ESM TypeScript, no dependencies. It reads `MAKEFUN_OUTPUT_DIR`
(default `/output`), creates that directory, and writes the digits plus a
single trailing newline to `entry.txt`. The bytes are fixed, so every run
is identical.
